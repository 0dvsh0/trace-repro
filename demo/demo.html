Three services.
Three concurrency bugs.
One engine that closes them.

Not a payments demo. A lost update in checkout, an oversell in inventory, and a duplicate charge in payments — three different services, three different tables, three different failure modes, the same engine. Every screenshot on this page is a real window on a real run; every number is read back out of the graph that run produced.

lost update · checkout-svc oversell · inventory-svc duplicate delivery · payments-svc same fix everywhere: row lock + idempotency key
